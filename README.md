# mini tools

ブラウザだけで動く、ちいさな道具箱。外部依存なし（CDN・フレームワーク不要）の静的ページを GitHub Pages で公開している。

入口: `https://little-hands.github.io/mini_tools/`

## 収録ツール

| ツール | URL | 概要 |
|---|---|---|
| あみだくじ抽選 | `/mini_tools/amidakuji/` | 候補と当選数を入れると、あみだの線をたどって当選者を決める |
| チャオチャオ サイコロ | `/mini_tools/dice/` | 1・2・3・4・✕・✕ の6面をランダムに出す |

## 構成

```
index.html          入口（TOOLS 配列にツールを列挙）
amidakuji/          あみだくじ抽選
  index.html / style.css / app.js
dice/               チャオチャオ サイコロ
  index.html        1ファイル完結
```

ディレクトリ名がそのまま公開URLのパスになる（Pages の配信元は `main` ブランチのルート）。

## ツールを増やすとき

1. 新しいディレクトリを作って `index.html` を置く
2. ルート `index.html` の `TOOLS` 配列に1行足す
3. `main` へ push すれば数分で公開される

## あみだくじ抽選の使い方

1. 候補名を改行区切りで入力
2. 当選数を指定
3. **START** ボタンを押すと、上のカードがフリップして「当たり / ハズレ」が見える
4. 当たりカードから玉が出てあみだの線をたどり、下端の名前に到達 → 当選

`Cmd / Ctrl + Enter` でも抽選実行可。

## チャオチャオ サイコロの使い方

サイコロかボタンをタップ（スペース / Enter でも可）。下部に直近8回の履歴が出る。
実物と同じく `1・2・3・4・✕・✕` の6面構成なので、✕ が出る確率は 2/6。
